+## API contract (m├¡nimo implementable hoy)
+
+- GET /health
+  - 200: { status, timestamp, version, database }
+
+- POST /tickets
+  - body: { passenger_id, trip_id, seat_number?, payment_method, idempotency_key? }
+  - flow:
+    1. check idempotency -> if exists return existing ticket
+    2. validate passenger: GET `${MS_PASSENGERS_URL}/passengers/{passenger_id}` (optional retries)
+    3. validate trip: GET `${MS_TRIPS_URL}/trips/{trip_id}` -> must return base_price/currency (and optionally available_seats)
+    4. call Redis Lua script to atomically: check seats >0, decr seats, create ticket hash, add to passenger set, set idemp mapping
+    5. process payment mock (optional), set booking_status confirmed
+  - success 201: { message: 'Ticket purchased successfully', data: { ticket_id, passenger_id, trip_id } }
+  - errors: 400 invalid input, 404 passenger/trip not found, 409 no seats, 503 external service error
+
+- GET /tickets/{id}
+- POST /tickets/{id}/cancel
+- GET /tickets/passenger/{passenger_id}/history

+## Redis data model (summary)
+
+- Key: `trip:<trip_id>:available_seats` => integer
+- Key: `ticket:<ticket_id>` => hash fields: ticket_id, passenger_id, trip_id, seat_number, total_price, currency, booking_status, created_at, updated_at, idempotency_key
+- Key: `tickets:by_passenger:<passenger_id>` => set of ticket ids
+- Key: `idemp:<idempotency_key>` => ticket_id (optional TTL)

+## Atomic Lua script (ejemplo) y uso con Spring
+
+Ejemplo Lua (reservar y crear ticket):
+
+```lua
+-- KEYS[1] = trip:<trip_id>:available_seats
+-- KEYS[2] = ticket:<ticket_id>
+-- KEYS[3] = tickets:by_passenger:<passenger_id>
+-- ARGV: ticket_id, passenger_id, trip_id, seat_number, total_price, currency, booking_status, created_at, idempotency_key
+
+local seats = tonumber(redis.call('get', KEYS[1]) or '0')
+if seats <= 0 then return {err='NO_SEATS'} end
+if redis.call('exists', KEYS[2]) == 1 then return {err='TICKET_EXISTS'} end
+redis.call('decr', KEYS[1])
+redis.call('hmset', KEYS[2], 'ticket_id', ARGV[1], 'passenger_id', ARGV[2], 'trip_id', ARGV[3], 'seat_number', ARGV[4], 'total_price', ARGV[5], 'currency', ARGV[6], 'booking_status', ARGV[7], 'created_at', ARGV[8])
+redis.call('sadd', KEYS[3], ARGV[1])
+if ARGV[9] and ARGV[9] ~= '' then redis.call('set', 'idemp:'..ARGV[9], ARGV[1]) end
+return {ok='OK'}
